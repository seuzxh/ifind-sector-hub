ifind 板块/概念数据层公共组件

从 monitor（ifind-sector-attribution）抽离的公共数据层：iFinD 数据源客户端、三表快照存储、同步编排，供多平台复用。

这个组件做什么

一句话：输入一个 iFinD 账号，产出一个可直接查询的"板块 × 概念 × 个股"SQLite 快照库， 并把取数、落库、日更新整条链路的复杂度从业务代码里收走。具体承担四件事：

  • 取数——封装 8 个 iFinD HTTP 端点（个股概念 / 成分股 / 行情 / 概念信息 / 智能选股），自带 token 生命周期管理（401 双检刷新、flock 跨进程共享、轮换落盘）、指数退避重试与批量分片；消费方不碰 HTTP 细节。
  • 落库——三张表（概念字典 / 概念成分股 / 个股-概念映射）的建表、幂等写入与 MAX(date) 最新快照读取；一次接入，所有消费方共享同一份口径。
  • 日更——同步编排管线：字典初始化 → 成分股 8 线程并发拉取（失败不中断）→ 个股映射 → 全市场扫描补全新概念 → 观察池刷新。
  • 供数——Python SDK（SectorHub 门面）进程内直用，或挂一个可选 FastAPI 路由对非 Python 消费方供数。

适合谁用：任何需要"这只股票属于哪些概念 / 这个概念有哪些成分股 / 现在市场上有哪些板块"的下游—— 板块归因监控（monitor 即首个消费方）、实时行情引擎、知识图谱数据源、主题催化分析等。

模块一览

模块职责关键点
core.codes A股代码/前缀过滤 is_a_share_code（沪深北后缀）/ is_a_share_concept（700/881/883/884/885/886 前缀白名单，海外概念返回 False）
core.tokens token 生命周期管理 TokenStore 进程内双检；FileTokenStore JSON + flock 跨进程持久化，REFRESH_TOKEN 轮换自动落盘
integrations.ifind.client iFinD API 客户端 接口 1-6 + 实时行情 + smart_pick 智能选股；get_all_ths_boards 动态枚举板块全集（concept / industry_l2 / l3）、search_board_by_name 按名搜板块；接口3/4 走 ft.10jqka 网关、其余走 quantapi；401 自动刷新后仅重试本轮一次
repositories.storage 三表存储 ths_concept_dict / concept_members / stock_concept_map；MAX(date) 快照语义；replace 级联 + 同事务迁移钩子；get_concept_members_map 批量读 + 5 个只读访问器（monitor 裸 SQL 统一入口）
services.sync 同步编排 字典初始化、成分股线程池并发（失败不中断）、个股-概念映射、全集补全、观察池刷新
api.service可选 FastAPI 服务层 build_router(hub) 挂载即用：3 个只读端点 + 1 个同步触发端点；面向非 Python / 跨机消费方，凭据集中在服务端（与 SDK 的差异与选型见设计方案 §8）；pip install "ifind-sector-hub[service]"
SectorHub 门面 聚合 client / store / sync，共享同一 token 管理与 SQLite 库文件；HubConfig 数据类集中配置

快速开始

pip install -e /root/Projects/ifind-sector-hub
# 可选服务层：
pip install -e "/root/Projects/ifind-sector-hub[service]"

from ifind_sector_hub import SectorHub, HubConfig, FileTokenStore

hub = SectorHub(HubConfig(
    db_path="data/sector_attribution.db",          # 任意 SQLite 库文件
    access_token="...", refresh_token="...",       # 首次 bootstrap（或环境变量 IFIND_*）
    token_store=FileTokenStore("data/token.json"), # 可选：刷新/轮换跨进程落盘
))

hub.client.smart_pick_stocks("机器人概念板块成分股")   # 数据源（含 smart_pick_boards 枚举板块）
hub.store.get_concept_members_map(["885001.TI"])    # 三表快照读（不传日期=最新快照）
hub.sync.sync_concept_members(["885001.TI"], "20260918")  # 并发拉成分股入库

语义注意事项（沿用 monitor 原语义）

日期格式跨表不一致：字典/映射表使用 YYYY-MM-DD，成分股表使用 YYYYMMDD。 这是从 monitor 原样保留的历史语义，消费方拼接查询时需注意。
永久缓存快照语义：三表读方法不传日期时取 MAX(date) 最新快照，历史数据不清理、不去重。
迁移钩子：replace_concept_dict(boards, migrate_hook) 的钩子在同一事务/同一连接内执行， 用于迁移消费方自己的关联表（如 monitor 的 watched 勾选），保证原子性。
