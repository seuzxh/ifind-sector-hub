行情缓存设计（P0）P0 已实施

目标：把本组件升级为 ifind 概念/行业板块的核心数据源——板块历史成分股与板块行情（日频/分钟频）落库缓存，读路径懒加载（库里有就不打接口，缺的只取缺失部分），配 FastAPI + Vue 看板查看与维护。

已确认的五项决策（2026-10-15）： ① 板块均为指数，行情只存不复权（无 CPS 版本维度，台账简化）； ② 按需请求，回溯下界近 5 年，同样按需； ③ 看板 FastAPI + Vue； ④ 存储先用 SQLite； ⑤ 懒加载语义 立即返回已有 + 后台补全。

2. 数据模型（DDL）

-- 日频行情（不复权指数）
CREATE TABLE IF NOT EXISTS quotation_daily (
    code          TEXT NOT NULL,     -- 板块指数代码，如 885001.TI
    trade_date    TEXT NOT NULL,     -- YYYY-MM-DD
    open REAL, high REAL, low REAL, close REAL,
    volume REAL, amount REAL, change_ratio REAL, pre_close REAL,
    PRIMARY KEY (code, trade_date)
);

-- 分钟频行情（1min bar；按 code 前两位可再按年分表，P2 视体量决定）
CREATE TABLE IF NOT EXISTS quotation_minute (
    code       TEXT NOT NULL,
    bar_time   TEXT NOT NULL,        -- YYYY-MM-DD HH:MM
    open REAL, high REAL, low REAL, close REAL, volume REAL,
    PRIMARY KEY (code, bar_time)
);

-- 覆盖台账：完整性判定的唯一事实源（缺失 = 无行）
CREATE TABLE IF NOT EXISTS quotation_coverage (
    code        TEXT NOT NULL,
    freq        TEXT NOT NULL,       -- '1d' | '1m'（1m 以"日"为覆盖单位）
    trade_date  TEXT NOT NULL,
    state       TEXT NOT NULL,       -- 'complete' | 'empty'（负缓存：确认无数据）
    fetched_at  TEXT NOT NULL,
    PRIMARY KEY (code, freq, trade_date)
);

-- 交易日历（周末/节假日不算缺口；来源 get_trade_dates 专用接口，默认 2020-2028 全覆盖 2182 天，
-- 含未来日期；实测回溯上限 1990-12-19 A股开市日）
CREATE TABLE IF NOT EXISTS trading_calendar (
    trade_date TEXT PRIMARY KEY
);

-- 后台补全任务表（进程退出不丢，任一进程/看板触发即恢复消费）
CREATE TABLE IF NOT EXISTS fill_tasks (
    task_id    INTEGER PRIMARY KEY AUTOINCREMENT,
    code       TEXT NOT NULL,
    freq       TEXT NOT NULL,
    d_start    TEXT NOT NULL,
    d_end      TEXT NOT NULL,
    status     TEXT NOT NULL DEFAULT 'pending',  -- pending|running|done|failed
    attempts   INTEGER NOT NULL DEFAULT 0,
    last_error TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

规模测算（710 板块 × 5 年）：日频约 89 万行、分钟频约 8.4 亿行——分钟频按需触发（决策②）天然限量； SQLite 写入走批量事务，读走 PK 索引，日频完全无压力；分钟频若后续出现压力再按年分表或评估 DuckDB（决策④留了口子）。

3. 覆盖台账算法（区间减法）

  1. 请求 (code, freq, [d0, d1])，d0 早于库内最早已确认日期时按 today − 5y 收敛（决策②回溯下界）；
  2. 查 trading_calendar 得交易日集合 T（非交易日不算缺口）；
  3. 查 quotation_coverage 已确认集合 C（complete 与 empty 都算已确认）；
  4. 缺口 M = T − C：
    • M = ∅ → 纯读库返回，state='complete'；
    • M ≠ ∅ → 立即返回已有 bars（state='partial'，附 missing_dates）并投递后台补全任务（决策⑤）；
    • 命中 empty 的日期直接返回空，不打接口（负缓存）。
  5. 后台任务分片拉取（日频 ≤90 天/片、分钟 ≤5 天/片，片长按实测修正）：INSERT OR REPLACE 入库 → 逐日 upsert 台账：有 bar 写 complete，交易日但 0 bar 写 empty。

新鲜度边界：当日数据未收盘会变——今日（及分钟频当日已过但未收盘时段）不得写 complete；收盘判定以日历+时钟为准，次日重查自然覆盖。
